# Installing on Hostinger? Start here

**[Download the Hostinger ZIP](downloads/emotional-spending-hostinger.zip)** · **[Read the Hostinger setup guide](HOSTINGER-SETUP.md)**

Open the ZIP file on GitHub and click **Download raw file**. This runtime-only package removes Python/build/test files and uses Hostinger's `public_html` layout.

Use **File Manager**, not the website-migration / upload-backup screen. Extract in the domain directory containing `public_html`, so `public_html` and `emotional-spending-private` are siblings. Follow the guide for database configuration and first-time administrator setup. Back up an existing site before changing its files.

Validated locally: all 17 browser-test groups, including image uploads. No live Hostinger account or migration-tool acceptance test was performed.
